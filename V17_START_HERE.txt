ＧＡＭＥＲ-ＣＯＲＰ — V17 BUILD (ZIP QUICK START)
================================================

কী কী আছে
- Operator dashboard : static/index.html   (লগইন + লাইভ লগ + বট রোস্টার + সেটিংস)
- Public board       : static/public.html  (রিড-অনলি লেভেল বোর্ড)
- Admin script       : static/js/app.js
- Public script      : static/js/public.js
- Styles             : static/css/ui-v17.css  (নতুন), ui-v14.css, theme.css
- Server             : app/ (FastAPI + SQLite + lv.py worker)
- Checks             : tests/

ফিচার
- UID+password অথবা Access Token দিয়ে অ্যাকাউন্ট যোগ, এডিট, বাল্ক অ্যাড/অ্যাকশন
- প্রতিটা বটের আসল সেভড প্রোফাইল: Level, EXP, next-level progress
- Live log: প্রতিটা ইভেন্ট (queue, UDP join, timeout, cooldown, profile change, level up)
- Errors: ব্যর্থ রিকোয়েস্ট, সেশন শেষ, কানেকশন সমস্যা — সব দেখা যায় ও ডিসমিস করা যায়
- লেভেল বাড়লে স্ক্রিনে বড় LEVEL UP কার্ড (আসল সেভড প্রোফাইল থেকে)
- Level progress তালিকা, ফ্লিট সামারি, রিজিওন ডায়াগনস্টিক, মেটাডেটা এক্সপোর্ট/ইমপোর্ট
- Public রিড-অনলি বোর্ড: সেভড প্রোফাইল কার্ড + অটো রিফ্রেশ


ডেইলি EXP টার্গেট (অটো অফলাইন) — নতুন
- LV 1-29  : দিনে সর্বোচ্চ ৫,০০০ EXP — টার্গেট হলে বট নিজেই অফলাইন হয়ে যায়
- LV 30-100: দিনে সর্বোচ্চ ৫০,০০০ EXP — টার্গেট হলে বট নিজেই অফলাইন হয়ে যায়
- গণনা হয় শুধু সার্ভার-ভেরিফায়েড প্রোফাইল EXP থেকে (queue/UDP কিছুই যোগ হয় না)
- রিসেট: প্রতি রাত ১২:০০ (UTC+6, ডিফল্ট) — এর আগে Start চাপলে পরিষ্কার মেসেজ দেখাবে
- আবার চালু করতে: বটের ড্রয়ারে "Reset today's EXP" অথবা Roster-এর bulk "Reset today's EXP"
- সব অ্যাকাউন্টের কাউন্টার একসাথে মুছতে: Settings → Daily limits → Reset every account today
- লিমিট বদলাতে .env: DAILY_EXP_LOW_LIMIT=5000, DAILY_EXP_HIGH_LIMIT=50000, DAILY_EXP_LOW_LEVEL_MAX=29,
  DAILY_EXP_RESET_OFFSET_HOURS=6, DAILY_EXP_AUTO_RESUME=false


EXP না বাড়লে এখন সাইটই কারণ দেখাবে — নতুন
- বট ৫ ঘণ্টা ম্যাচ দেখালেও EXP না বাড়লে রোস্টার রো-তে হলুদ ব্যাজ আসবে:
  "NO EXP FROM SERVER · কত সময় · কতবার চেক" — ড্রয়ারে পুরো কারণ লেখা থাকবে।
- EXP গেম সার্ভারই দেয়, আর দেয় ম্যাচ "settle" (ফলাফল নিশ্চিত) হওয়ার পরে।
  শুধু join করে ম্যাচ শেষ না হলে / যে মোডে রিওয়ার্ড নেই / অ্যাকাউন্টের নিজের দিনের EXP লিমিট শেষ
  — এসব ক্ষেত্রে EXP ০ আসবে, সাইট থেকে জোর করে EXP বানানো সম্ভব নয়।
- কোনো সন্দেহ থাকলে: বাস্তব ডিভাইসে ওই UID দিয়ে একটা ম্যাচ খেলে শেষ করুন, তারপর
  ড্রয়ারে "Check profile EXP" চাপুন — সত্যিকারে EXP বাড়লে কয়েক সেকেন্ডেই দেখা যাবে।
- চেক করার গতি বাড়াতে: PROFILE_POLL_SECONDS (ডিফল্ট ৪৫s, সর্বনিম্ন ১৫s),
  সতর্কবার্তার সময়: EXP_STALL_MINUTES (ডিফল্ট ৩০ মিনিট),
  ম্যাচ কাটা পড়লে লম্বা রাখতে: UDP_IDLE_RECONNECT_SECONDS (ডিফল্ট ১৮০s)।


হোস্টিং সার্ভার ও গেম সার্ভার — দুটোই নিরাপদ (নতুন)
- গেম সার্ভারে বাড়তি কোনো ট্রাফিক যোগ হয়নি। ম্যাচে যাওয়া UDP প্যাকেট আগের মতোই হুবহু একই
  (টেস্টে বাইট-বাই-বাইট মিলিয়ে দেখা হয়েছে)।
- প্রোফাইল চেক: প্রতি অ্যাকাউন্টে সবচেয়ে দ্রুত ১৫ সেকেন্ডে ১ বার (ডিফল্ট ৪৫s), একসাথে
  সর্বোচ্চ ৩টা চেক (PROFILE_CHECK_CONCURRENCY), ম্যাচ শুরু/শেষে বাড়তি চেকও ১০ সেকেন্ডে ১ বারের বেশি নয়।
- গেম API এরর দিতে থাকলে বট নিজে থেকেই ধীরে হয় (ব্যাকঅফ), সর্বোচ্চ ৩০০ সেকেন্ড পর্যন্ত অপেক্ষা করে
  — মানে সার্ভারে চাপ বাড়ে না, কমে।
- হোস্টিং সার্ভার: MAX_ACTIVE_WORKERS / MAX_CONCURRENT_LOGINS সীমা আগের মতোই, অ্যাকাউন্ট বন্ধ করলে
  তার মেমোরি তথ্য মুছে যায়, কাউন্টার সীমিত (মেমোরি বাড়ে না), নতুন কোনো টাইমার যোগ হয়নি।
- Settings → 06 / SERVER SAFETY প্যানেলে দেখতে পাবেন: প্রতি মিনিটে কত প্রোফাইল রিড, গেম API স্টেট,
  সমান্তরাল রিড, ফেইল রিড, চালু ওয়ার্কার, ইন্সট্যান্সের মেমোরি, CPU লোড/কোর, ডেটা সাইজ + এক লাইনের রায়।
- ডিটেইল চাইলে: GET /api/health (অ্যাডমিন) — হোস্ট ও গেম-API দুটোর পূর্ণ চিত্র। /health খোলা ও হালকা
  (হোস্টিং প্ল্যাটফর্মের liveness probe-এর জন্য)।


এই বিল্ডে ঠিক করা হয়েছে (আগের সমস্যা থাকলে এখন ঠিক হয়ে যাবে)
- "EXP limit আসেনি / অনেক ফিচার কাজ করে না" — এর আসল কারণ ছিল ব্রাউজারের পুরনো ক্যাশ: app.js পুরনো

  /admin ও / কোনো ক্যাশ রাখে না, /static ফাইল প্রতিবার রিভ্যালিডেট হয় ⇒ নতুন আপলোড দিলে সাধারণ
  রিলোডেই নতুন UI আসবে, হার্ড রিফ্রেশ দরকার নেই।
- এখন সাইটেই দেখা যাবে কোন বিল্ড চলছে: হেডারে "BUILD 18.4", আর /health লিংকে build নাম্বার।
  BUILD 18.4 দেখলে বুঝবেন নতুন কোড চলছে।
- Live log ঠিক করা হয়েছে: আগে WebSocket দিয়ে আসা নতুন ইভেন্ট (ডেইলি টার্গেট স্টপ, LEVEL UP, EXP
  স্টল) সরাসরি লগে আসত না, ৮ সেকেন্ডের পোলের জন্য অপেক্ষা করতে হত। এখন সাথে সাথেই লগে দেখাবে।
- ব্রাউজার লেভেলে টেস্ট যোগ করা হয়েছে (jsdom): ৫৭টি চেক — লগইন, ডেইলি EXP ডেক, EXP স্টল ব্যাজ,
  লাইভ লগ (পোল + WebSocket), সেফটি প্যানেল, fast mode, থিম, ড্রয়ার, মডাল, bulk add, chart, sign-out,
  পাবলিক বোর্ড — সব সত্যি ক্লিক করে দেখা হয়েছে।


২টা বড় সমস্যা ঠিক করা হয়েছে (আপনার স্ক্রিনশট অনুযায়ী)
১) ফোনে Add Bot / EXP reference পপআপ অর্ধেক স্ক্রিনের বাইরে চলে যেত (একটা CSS নিয়ম দুইবার
   সেন্টার করছিল)। এখন ৩২০px ফোনেও পপআপ পুরো স্ক্রিনে ঠিকভাবে বসে, সব ঘর পুরো চওড়া —
   ব্রাউজার টেস্টে যাচাই করা (০টি ওভারফ্লো)।
২) "১টা আইডি দিলে EXP আসে, ২-৪টা একসাথে Start দিলে কিছুই আসে না" — কারণ: সব অ্যাকাউন্ট একই
   সেকেন্ডে লগইন আর ম্যাচ রিকোয়েস্ট পাঠাচ্ছিল। গেম সার্ভার সেটাকে burst ধরে থ্রটল করে ⇒ ম্যাচ
   হয় কিন্তু settle হয় না ⇒ EXP ০। এখন:
   - ACCOUNT_START_STAGGER_SECONDS=4 → একসাথে Start দিলে প্রতিটি অ্যাকাউন্ট ৪ সেকেন্ড পরপর
     লগইন শুরু করে (সাইটে সাথে সাথে "started" দেখাবে, অপেক্ষা সাইটে নয় — ভিতরে হবে)
   - MATCHMAKING_MIN_GAP_SECONDS=1.2 → সব অ্যাকাউন্ট মিলিয়ে দেড় সেকেন্ডে ১ বারের বেশি
     ম্যাচ রিকোয়েস্ট যাবে না (আগে ৪ অ্যাকাউন্টে প্রায় ১.৩ রিকোয়েস্ট/সেকেন্ড যেত)
   - ১টি অ্যাকাউন্টে আগের মতোই দ্রুত কাজ করে (কোনো অপেক্ষা নেই)
   Settings → 06 / SERVER SAFETY প্যানেলে এই দুটো সংখ্যা এখন দেখা যাবে।

চালু করার নিয়ম
1) python3 -m venv venv && source venv/bin/activate      (Windows: venv\Scripts\activate)
2) pip install -r requirements.txt
3) cp .env.example .env      → নিজের শক্তিশালী ADMIN_PASSWORD (১২+ অক্ষর) বসান
4) uvicorn app.main:app --host 0.0.0.0 --port 8000
   অথবা: python3 run.py

খোলার ঠিকানা
- Public board : http://localhost:8000/
- Operator     : http://localhost:8000/admin   (username: admin, password: .env এর মান)
- API docs     : http://localhost:8000/docs

দ্রুততার জন্য
- ডিফল্টে "Fast mode" চালু থাকে: সব ব্যাকগ্রাউন্ড ও অ্যানিমেশন স্থির, কোনো পারালাক্স/টিল্ট চলে না।
- দুর্বল ডিভাইসে অটো-ডিটেকশন নিজেই ফাস্ট মোডে রাখে। ইমারসিভ ইফেক্ট চাইলে উপরের টগল বা
  Settings → Speed & effects থেকে চালু করুন।
- ব্রাউজার/ডিভাইস "reduce motion" সেটিংকে সবসময় মানা হয়।

নিরাপত্তা
- এই ZIP-এ কোনো .env, SECRET_KEY, FERNET_KEY বা data/ ডেটাবেস নেই — প্রথম রানেই তৈরি হবে।
- HTTPS ব্যবহার করুন এবং .env, SECRET_KEY, FERNET_KEY ও data/ ফোল্ডারের ব্যাকআপ রাখুন।
- EXP/লেভেল শুধু সার্ভার প্রোফাইল থেকে আসে; UDP JOIN মানেই রিওয়ার্ড নয় — ড্যাশবোর্ড সেটাই দেখায়।
